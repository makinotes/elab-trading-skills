# elab-coach · 交易能力诊断与纠正

用你的交割单、立案记录、几道情景题和你自己的描述，看清六个交易能力维度（机制理解、风险与仓位、进场、退出、执行一致性、复盘统计）现在在哪一级；每次只挑最该补的一项，写成一条你自己确认的规则，跟练十笔或四周后复测。每个维度、每张处方都对应 [EdgeLab 交易公理](../_shared/trading-axioms.md) 中的一条。

- **什么时候用**：总是赚了拿不住、亏了死扛、临时起意交易多，或想知道自己这个月该练什么。
- **提供什么**：可选的交割单或 `elab-trade` 立案记录；没有记录也能从情景题和自述开始。
- **得到什么**：一份六维能力画像、一张只含一个指标的处方、跟练计数和复测结论，保存在本机 `~/.elab/coach/`。
- **边界**：不预测行情，不给买卖方向、加减仓或具体仓位；规则的数值由你按自己的资金决定。十笔的跟练只检查是否照做，不证明策略有效。

示例：「我总是赚了拿不住、亏了又扛着，帮我看看该先练什么。」

决定一笔具体交易用 [elab-diagnosis](../elab-diagnosis/README.md)；记录和复盘成交用 [elab-trade](../elab-trade/README.md)。
