# 画像、处方、跟练与复测记录

目录：`<状态根>/coach/`（状态根按 `_shared/schema.md §一`）。只在用户同意保存或明确要求记录时写入；纯诊断对话不落盘。

写入规则沿用 `schema.md`：`mkdir -p` 后以「只新建、已存在即失败」方式创建；时间戳用 `date +%Y%m%d-%H%M%S`，禁猜；写后读回核验；画像、处方、复测写完不改，变化新建带时间戳的版本；`跟练记录.md` 只追加。所有文件 `data_classification: private`，不进任何公开仓库。

target: 9/10   # 用户确认的达标线；未写时按 trading-ability.md 默认（≥90% 且 n≥5）
count_basis: 立案「止盈规则」行的挂单时间或状态；未写视为信息不足
cycle: 十笔或四周，先到者为准
deadline: <YYYY-MM-DD>   # date -v+28d；四周到期 n<5 时延长，最长八周

处方需要调整时，新建一份并在 frontmatter 写 `supersedes: 处方_<旧时间戳>_<维度>.md` 与调整依据；旧处方保留。

**处方生命周期**：处方文件写完不改，`status: active` 只是创建时的标记，不会被改成别的值。当前处方的判定：最新一份既没有被任何复测的 `closes` 引用、也没有被任何处方的 `supersedes` 引用的处方。复测写完即关闭它所 `closes` 的处方；延长处方新建一份并写 `supersedes`。路由判断「有没有未结束的处方」用这条规则，不看 `status`。

## 跟练记录 `跟练记录.md`（只追加）

```markdown
| 日期 | 处方 | 开仓快照 | 是否达标 | 偏离分类 | 情境（自述） | 备注 |
|---|---|---|---|---|---|---|
| 2026-10-08 | 处方_20261001-..._D4 | 开仓_2026-10-08_XYZ.md | 是 | 符合规则 | | |
| 2026-10-12 | 处方_20261001-..._D4 | 开仓_2026-10-12_XYZ.md | 否 | 无依据的偏离 | 盘中，手机下单后进会议 | [自述] 当天没来得及挂单 |
| 2026-10-15 | 处方_20261001-..._D4 | 无立案 | 信息不足 | 信息不足待核 | | 用户不记得当天有没有挂单 |
```

偏离分类只用 `_shared/trading-consistency.md` 的四个值：符合规则、有依据的修订或例外、无依据的偏离、信息不足待核。它分类的是这笔动作与计划的关系，不是对人的评价。没有对应开仓快照的交易：开仓快照列写「无立案」；是否达标按用户当场补充的信息填，补不了写「信息不足」；偏离分类写「信息不足待核」；计入周期笔数的分母。这只说明本轮缺记录，不表示用户当时没有计划。「情境」列只记用户自己说出的时段或触发源（盘中、收到推送、群里看到、深夜），供下一张处方的环境改造取材；用户没说就留空，不推断。

## 分享版（用户要求发到公开位时另存，不改动原档）

文件名 `分享_<时间戳>.md`，正文只含用户逐项点名保留的内容；默认删除金额、胜率、盈亏比、持仓数、标的名、情景题题号与自述原话，以及立案快照、交割单等原文件名；保留的维度等级与判断带 `[AI推测]`；不带品牌页脚，末尾一句「本人自评记录，由 EdgeLab Trading Skills 工具整理，不代表 EdgeLab 对其交易能力的评定或任何投资建议」。frontmatter 加 `type: coach-profile-share`、`data_classification: public` 与 `derived_from: <画像文件名>`（画像文件名只含日期，可以保留）。用户没有点名的内容一律不写，等级含义图例与公理说明也要点名才保留。
