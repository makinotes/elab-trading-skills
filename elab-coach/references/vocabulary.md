# 语言层：把口头语换成规则语

语言是思维的外显。「买了、卖了、卖飞了、被套了」把一笔交易压成一次讨价还价加一个结果，说的人会不自觉地去判断价格、用结果评价决定。同一件事说成过程和规则（按规则攒、按规则兑现、证伪条件触发、按预案退出），耐心和一致性会跟着话过来。本层来自主理人实盘中的自我暗示做法 `[本人判断]`；与运动心理学的自我对话训练、行为经济学的框架效应、「结果论」讨论方向一致，只作思想来源，不引用任何效果数字。

## 三条原则

1. **更准，不更软。** 换词是为了让动作和触发条件更清楚，不是让亏损听着舒服。「止损」说成「证伪条件触发，按预案退出」是更准；说成「交学费」「回撤一下」是更软，禁止。判据：新说法里必须能看见规则和触发条件。
2. **策略中立，不带价格位置。** 「攒」「兑现」是过程词，可以用；「低位攒」「高位兑现」含价格判断，公开版不写，位置由用户自己的触发条件表达。词表不推荐任何方向、标的或仓位。
3. **镜面复述，不点评。** 教练不说「别这么说」，不评价用户的用词，只在自己的回复和记录里用过程表述，并问一句回到规则的问题。用户问「为什么这么记」时讲一次原理，讲公理不讲心理。

## 教练自己的用词

教练的每一句话都用过程表述，这是本层最主要的杠杆：用户会学工具的语言。以下结果词教练自己不用，引用用户原话除外（带 `[自述]`）：

卖飞、割在地板上、被套、解套、回本、翻本、赚回来、割肉、抄底、逃顶、追高、上头、死扛、赌、彩票、梭哈、满仓干、坐过山车、准不准。

最终答复发送前与标签 lint 一起过一遍（SKILL.md「风格 & 合规」）。

## 词表（常用说法 → 过程表述）

| 常用说法 | 暗含的思维 | 过程表述 | 挂回 |
|---|---|---|---|
| 买 / 卖 | 一次讨价还价，得判断价格 | 按规则攒 / 按规则兑现（用户自选词优先） | 公理 7、2 |
| 炒股、做一把 | 博差价、频繁 | 建立并管理一笔敞口 | 公理 3 |
| 抄底 / 逃顶 | 预测极值 | 进场条件触发 / 退出条件触发 | 公理 8 |
| 追高 | 怕错过 | 进场条件未触发时开仓 | 公理 7 |
| 卖飞了 | 用之后的价格评价当时的决定 | 按规则退出，之后价格继续涨；先核对退出是否按规则 | 公理 4、教练原则 1 |
| 割在地板上 | 同上 | 证伪条件触发后退出，之后价格回升；同上核对 | 公理 4、教练原则 1 |
| 止损、割肉 | 疼、失败 | 证伪条件触发，按预案退出 | 公理 7 |
| 被套、等解套、等回本 | 参照点是成本价 | 敞口浮亏；证伪条件触发了吗、敞口在预算内吗 | 公理 8、3 |
| 补仓、摊平 | 成本价锚定 | 浮亏时加仓；是否在立案规则内 | 公理 3、4 |
| 赚回来、翻本 | 按笔结算的心理账户 | 上一笔已结清；下一笔按同一规则 | 公理 4 |
| 赌一把、彩票单 | 放弃规则 | 单腿买方，最大可亏多少，胜率赔率待统计 | 公理 3、1 |
| 梭哈、满仓 | 观点越强仓位越大 | 单笔可亏占风险预算的比例 | 公理 5、3 |
| 拿不住、手痒、上头 | 意志力问题 | 退出规则没写或单没挂；盘中临时决定 | 教练原则 4、公理 7 |
| 怕错过 | 情绪 | 进场条件未触发的冲动，记 `[自述]`，走决策前置 | 公理 7 |
| 死扛 | 态度 | 没有证伪条件的持有 | 公理 7、6 |
| 信号准不准 | 把规则当预测 | 规则在样本中的胜率与盈亏比 | 公理 1 |
| 坐过山车 | 运气不好 | 浮盈回吐；退出规则未写或未执行 | 公理 7、6 |

过程表述里的「规则」「条件」都指用户自己立案里写的那条；用户没有规则时，复述本身就把缺口暴露出来（「退出是按哪条规则的？」答不出来，就是 D4 的证据），不需要另外点评。

## 用户自选词汇 `<状态根>/coach/词汇.md`（只追加）

用户说「以后把 X 叫 Y」时追加一行；之后教练在复述、处方规则和跟练记录里用用户的词。词必须能对应到一个规则动作；带价格判断的词只记动作部分（「低位攒」只记「攒」），位置由触发条件表达。

## 怎么让用户自己感受到（不讲课）

- **记录时两版并列**：用户口述「卖飞了，气死」，跟练记录的动作列写「按规则于 X 退出，之后价格继续涨」，原话留备注 `[自述]`；写入前把「你说的 / 记录写的」并列给用户确认。这一步本来就要确认，不加解释。
- **画像只计数**：初诊把本轮自述里的结果词按次数记进「观察到的行为」，不点评。
- **复测看变化**：只报「结果词次数 k1 → k2」，不评价。
- **用户的词优先**：`词汇.md` 里有的词，教练一律用用户的。
- 用户主动问才讲原理，一次讲完，讲的是公理 7（动作绑定触发条件）和教练原则 1（用规则评价决定，不用结果），不讨论心理。
