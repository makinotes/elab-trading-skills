# elab-restore · 找回并接续投研存档

查找由 elab-save 保存的研究或决策存档，呈现上次的判断、待验证问题与下一步，帮助你恢复上下文。

- **什么时候用**：换了会话，想知道上次分析到哪里，或找回指定项目的记录。
- **提供什么**：项目名、存档编号或“接着上次”等请求；出现多个候选时需确认目标。
- **得到什么**：所选存档的关键状态和后续工作线索。
- **边界**：只恢复已有记录，不重新分析，也不把旧行情当作最新数据；没有存档时不会凭空补出历史。

示例：“找回上次的研究存档，告诉我还剩哪些问题。”

尚未存过进度时，先用 [elab-save](../elab-save/README.md)。
