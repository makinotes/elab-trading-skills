# elab-save · 保存当前投研进度

把当前对话已有的关键判断、已排除方向、待验证假设和下一步整理为结构化本地存档，便于以后接续。

- **什么时候用**：这次研究告一段落，想保留进度而不是下次从头解释。
- **提供什么**：当前已有的研究或决策内容，以及可选的存档标题、项目名。
- **得到什么**：一份保留来源与敏感级别的新本地 Markdown 存档和保存位置。
- **边界**：负责记录，不代做新的分析或决策；本地保存不等于自动跨设备同步，不上传到公开仓库。

示例：“把这次的判断、待验证假设和下一步存下来。”

下次用 [elab-restore](../elab-restore/README.md) 找回；多次存档可用 [elab-report](../elab-report/README.md) 整理。
