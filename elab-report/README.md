# elab-report · 合并存档生成投研复盘报告

读取同一项目的多份 elab-save 存档，按时间与主题合并、去重，整理判断如何演变、哪些假设仍待验证以及可复用的方法。

- **什么时候用**：想把一段时间的研究与历史复盘整理成一份可阅读、可归档的报告。
- **提供什么**：已有的本地存档，以及需要整理的项目。
- **得到什么**：保留来源标签与判断演变的 Markdown 复盘报告。
- **边界**：以已有存档为依据，不是从零撰写研报；对外分享前按受众与来源权限生成独立脱敏版；未知来源先核验，会员明细不进入公开版。已发布报告有误时保留原档并追加更正，生成文件不等于自动发送给别人。

示例：“把这个项目的多次存档整理成一份复盘报告。”

没有存档先用 [elab-save](../elab-save/README.md)；需要新研究用 [elab-research](../elab-research/README.md)。
