# elab-futu-research · 富途与老虎公开博主研究

在明确时间范围内归档博主可见的公开内容，结合发帖时点行情审阅观点、声称的交易与可核验证据，也支持多博主方法比较。

- **什么时候用**：研究博主的历史发言、交易风格、证据完整性或方法差异。
- **提供什么**：富途或老虎社区主页链接、明确的时间范围，以及归档、报告或比较等交付要求；数字 UID 默认按富途处理。
- **得到什么**：可续跑的公开内容归档、带证据边界的研究报告，以及按需生成的比较矩阵或规则卡。
- **边界**：不登录、不读取 Cookie，不访问你的证券账户。富途支持动态、专栏及公开媒体；老虎不支持专栏、媒体下载或转发识别。归档受公开接口和可见性限制，不能认证博主实际完整持仓或收益。机器自动分析默认标为探索性（exploratory），不等同人工核验的交易证据。

示例：“先确认时间范围，再整理这个博主的历史观点及相应证据。”

查看自己的富途持仓或成交，应使用 [elab-trade](../elab-trade/README.md) 的券商只读连接。
