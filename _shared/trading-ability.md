# 交易能力模型（跨 Skill 共享 · SSOT）

适用于 `elab-coach` 的诊断、处方与复测；其他 Skill 需要描述「交易能力」时引用本文，不另起定义。纯行情、概念或数学查询不必加载。

**地基是 `_shared/trading-axioms.md` 的八条交易公理。** 公理回答「交易应当怎样」，本模型把它们落到可观察的行为上，回答「你现在做到了哪一步」。每个维度、指标与补强顺序都挂回公理；公理与本文冲突时以公理为准。

## 定义

**交易能力**：在无法可靠预测行情的前提下，把观点稳定地变成可承受、可重复、可复盘的交易行为的能力。

它与投研能力分开：投研回答「方向怎么看」；交易能力回答「看法之后用什么工具、放多大、何时进、怎么走、做没做到、下次怎么改」。方向判断正确不保证盈利；方向判断一般的人，靠仓位、退出和复盘可以减慢亏损、留在市场，但流程本身不产生优势。本模型不评价用户的预测能力，也不据此推荐方向。

## 六个维度

| 维度 | 所落实的公理 | 核心问题 | 可观察证据（示例） |
|---|---|---|---|
| D1 机制理解 | 8 对不确定性定价（不懂结构就无从定价）；3 风险敞口（算不清就锁不住） | 知道这笔交易怎么赚、怎么亏吗 | 情景题能否自己算对并解释：组合盈亏、平仓要下什么方向的单与挂什么价、张数与保证金、到期损益、到期被指派后的持仓 |
| D2 风险与仓位 | 3 能控的只有风险敞口；5 仓位匹配 edge 与心态；8 目标是风险调整后收益 | 最坏情况是什么，账户扛得住吗 | 单笔最大可亏占风险预算、同时持仓数、单一标的集中度、杠杆叠加、是否存在一次清零的路径 |
| D3 进场 | 7 预案两阶段；2 少做噪音交易；1 规则可重复 | 观点有没有变成有条件的行动 | 立案是否写明观点、工具、期限、进场条件；计划外交易占比；用户有记录时，立案是否写明进场时的波动率环境 |
| D4 退出 | 7 预案两阶段；6 死拿是标的属性 | 进场前是否把止盈与证伪两侧都定好，且按标的类别分写 | 立案是否同时写明证伪条件与止盈规则；退出规则是否按标的类别分写；浮盈回吐幅度；亏损单与盈利单持有时长之比；临到期才处理的比例 |
| D5 执行一致性 | 4 交易一致性；2 控换手 | 同样条件是否用同样规则 | 计划与实际动作的偏差分类（按 `trading-consistency.md` 四类，含触发后未执行、条件未满足仍进场）；规则修订是否有依据与版本 |
| D6 复盘与统计 | 1 统计优势；8 目标是风险调整后收益 | 是否知道自己的真实胜率、盈亏比与期望 | 每笔是否有记录；胜率与盈亏比是否来自交割单；是否看过盈亏集中度、R 倍数分布或最大回撤，不只看期望；能否区分决策质量与结果 |

本表是维度与公理对照的唯一定义；`trading-axioms.md` 末尾按公理反向列出同一对照，`elab-coach` 各分册只引用维度编号。

维度边界：D3、D4 只评事前规则的存在与质量；实际动作与规则的偏离（触发后未执行、条件未满足仍进场、盘中临时交易）一律归 D5，同一件事不在三个维度重复计。没有立案的开仓是「没有事前计划」，归 D3。

情绪与心理不单列维度，作为 D4、D5 的观察角度：只使用用户明确表达的感受与可观察行为（例如「拿着等回本」「怕错过」「盯盘后临时下单」），不做心理诊断，不推断唯一动机。

## 四个等级

| 等级 | 名称 | 判定所需证据 |
|---|---|---|
| L0 | 未建立 | 说不出规则，或描述的规则与实际做法相反 |
| L1 | 有规则、靠感觉 | 能说出规则，但没有书面记录；执行依赖当时判断 |
| L2 | 书面化、大多照做 | 该维度的核心规则都已书面化（D4 须同时有止盈与证伪两侧）；最近一个跟练周期，或最近十笔带日期的事前记录中偏离少，偏离能说明原因 |
| L3 | 有记录、会迭代 | 至少十笔同类记录支撑；能说明规则在哪些条件下失效；如有修订，带依据与版本 |

- 等级是当前快照，不是对人的评价。
- 某维度缺少证据时记「待确认」，不猜等级；只有自述、没有记录或情景题时，最高记到 L1 并注明证据类型。
- **升级门槛**：处方指标达标与维度升级分开记。L1→L2 需要：一个跟练周期内处方指标达到处方写明的达标线（处方未写时，AI 模板默认为比例 ≥90% 且分母 n≥5，须经用户确认并标明来源），偏离能说明原因，且该维度的核心规则都已书面化；只练了其中一条、其余核心规则仍未书面化的，处方指标记达标、维度停在 L1，下一张处方补另一条。四周到期时 n<5，周期自动延长，最长八周；八周仍不足记 `[样本不足]`，不升级。L2→L3 需要跨周期累计至少十笔同一处方指标或同一策略类型的记录，并能说明规则的失效条件；修订可选，如有须带依据与版本。「同类」指同一处方指标或同一策略类型。证据满足更高等级的判定要求时可以跨级，例如从 L0 直接到 L2。
- **各维度的等级锚点**（执行类维度 D2–D5 直接用上表；D1、D6 用下面的锚点）：
  - D1 机制理解：L0 同类基础情景题错两道以上，或把结构的方向说反；L1 能说出结构但算不对盈亏、张数或保证金；L2 主要题型自己算对并能讲清；L3 对新结构能自写最多赚、最多亏、盈亏平衡点三句并在立案中核对。
  - D6 复盘与统计：L0 没有任何记录；L1 凭记忆或零散记录；L2 每笔至少三项记录并做过一次十笔复看；L3 按策略分组统计、决策与结果分开打分、有基准对比。
- L3 只说明记录与迭代的过程成熟，不证明策略有效；策略有效性仍按 `elab-trade` 交割单诊断的样本与分组要求判断。

## 证据类型与标签

| 证据类型 | 来源 | 标签 |
|---|---|---|
| 交割单指标 | `elab-trade` Mode B 的 FIFO 配对与量化底座 | `[我的数据]`，n<10 加 `[样本不足]` |
| 立案与回填 | `elab-trade` Mode A 的 `03_定格/` 快照 | 引用快照文件名 |
| 情景题 | `elab-coach` 情景题，用户当场作答；只作 D1 与 D2、D6 计算类题目的定级证据，D3–D5 的等级只看记录与自述，情景题在这几维只用于讲解 | `[情景题]` |
| 自述 | 用户在本轮明确说出的做法与感受 | `[自述]` |
| AI 归纳 | 由上述证据得出的维度判断 | `[AI推测]` |

标签含义只在 `schema.md §三` 定义，本表只列证据来源与对应标签。

## 能力指标（由交割单与立案计算，缺输入即写数据不足）

计算前提：
- 交割单类指标需要**逐笔配对明细**（每笔的标的、方向、开仓与平仓日期、盈亏、到期日）。`elab-trade` Mode B 的分组汇总表不含逐笔日期，只有汇总表时，持有时长、持仓峰值、临到期处理写数据不足。
- 立案类指标只在用户实际使用了 `elab-trade` 立案时计算。本轮没有任何立案记录时写「本轮无立案记录，待确认」，不得记 0 或 100%（见 `trading-consistency.md`「证据不足时如何判断」）。立案里的 `[待本人确认]` 占位视为未写明。
- n 指该指标自己的分母（例如加仓次数、开仓笔数），n<10 标 `[样本不足]`。

| 指标 | 定义 | 对应维度 |
|---|---|---|
| 同时持仓峰值 | 观察期内同时未平仓的最大笔数；需逐笔开平日期 | D2 |
| 单一标的集中度 | 最大单一标的的风险敞口占同期总风险敞口的比例（仅在可计算最大可亏时） | D2 |
| 杠杆叠加 | 同一标的同时持有正股、杠杆 ETF、该 ETF 期权等多层敞口的次数；需用户提供或确认产品类型与对应标的的映射（杠杆倍数、期权对应标的），无映射写数据不足 | D2 |
| 立案完整率 | 立案中同时写明证伪条件、止盈或退出规则、最大可亏的比例 | D3、D4 |
| 计划外交易占比 | 在用户已使用立案的前提下，没有对应立案的开仓占全部开仓的比例 | D3 |
| 条件未满足仍进场 | 有立案但进场条件未满足即开仓的次数；需立案写明进场条件 | D5 |
| 盈亏集中度 | 最大单笔亏损占同期总亏损的比例；盈利最大的三笔占同期总盈利的比例；需逐笔盈亏 | D6、D2 |
| 盈亏持有时长比 | 亏损单平均持有天数 ÷ 盈利单平均持有天数；需逐笔开平日期，按策略分组后解读 | D4 |
| 浮盈回吐 | 平仓盈亏相对持有期最大浮盈的差距；缺持有期逐日估值时写数据不足 | D4 |
| 亏损中加仓比例 | 在该标的浮亏时加仓的次数占全部加仓次数的比例；浮亏判定：正股按加仓成交价低于该标的当时的 FIFO 平均成本，收 credit 的期权组合按加仓时组合买回价高于开仓 credit，单腿买方与付 debit 的组合按加仓时市价低于开仓成本；缺加仓时点估值写数据不足 | D2、D4 |
| 临到期处理比例 | 期权在到期前最后一周内才平仓或被行权的比例；需到期日与平仓日 | D4 |
| 偏离分类 | 按 `trading-consistency.md` 把计划与动作的差异分为四类（符合规则 / 有依据的修订或例外 / 无依据的偏离 / 信息不足待核）的计数 | D5 |

指标只描述行为，不单独决定等级；需结合立案与自述核对原因。例如盈亏持有时长比偏高可能来自扛单，也可能来自策略本身持有期不同，须按策略分组后解读。

## 补强顺序

诊断结束时只给一项「现在最该先补的」，按能否继续留在市场排序：

1. **存在一次清零路径**（D2 为 L0，或存在杠杆叠加、单笔可亏超过承受能力）→ 先补 D2（公理 3：过注长期破产概率趋近 1，方向对也救不了）。
2. **D1 为 L0 且导致算不清风险** → 先补 D1，用模拟盘或用户自定的练习仓位练习。
3. **没有基准**（既没有来自交割单的胜率与盈亏比，也没有任何立案）→ 先补证据，并把它做成第一张正式处方：指标是记录率（每笔开仓有立案，或每笔平仓写三项最小记录），周期同处方；有历史成交的先走 `elab-trade` Mode B。这与 `elab-diagnosis` 体检模式的「先补哪个」第二条（胜率与盈亏比来自交割单）同源，是补证据，不是补 D6 能力。
4. 否则按 D4 → D5 → D2 → D3 → D6 → D1 的顺序选第一个未达 L2 的维度。D4 的退出规则在进场时写下，与 D3 一起在立案里完成，不是进场之外另一个动作。D1 为 L1 时，D4、D2 的处方开出前先做一道对应的算题（如 M-4、R-1），算不对先补 D1 那一题。
5. **D2 待确认**（缺风险预算或单笔最大可亏）时：先用一轮向用户要这两个数。给了按第 1 条判断；不给且已有结构风险证据（杠杆叠加、亏损中加仓、单腿买方为主）→ 先补 D2；不给且无结构风险证据 → D2 记待确认、按第 4 条继续，并在画像里注明尚未排除清零路径。

与 `elab-diagnosis` 体检的关系：两者优先级同源（先活下去，再有基准，再练）。体检是一次性拆整套打法，结论是「哪几项稳、哪几项是漏洞」；本顺序把它接成可训练的周期。用户带着体检结论来时，直接对应到维度，不重新排序。

## 边界

- 不评价、不推荐方向与标的；处方只写规则的形式，具体数值由用户按自身资金与承受力决定。
- 不判断用户是否适合交易；等级描述的是当前行为，不是对人的评价。
- 参考打法只作参照，用户自己的书面规则优先。
- 执行达标与策略有效分开下结论：十笔可以检查是否照做，不足以证明优势。
