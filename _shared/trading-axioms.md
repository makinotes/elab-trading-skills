# EdgeLab 交易公理（跨 Skill 共享 · SSOT）

整套 EdgeLab Trading Skills 在交易层的地基。提炼自主理人实盘交易系统并已脱敏，**策略中立**：不预设方向性、卖方或价差。各 Skill 引用本文，不各自复述；改公理只改这一处，并在 `CHANGELOG.md` 记录。

1. **散户稳定赚钱只有一条路：统计优势**——把买/卖打磨成"大样本下期望为正"的规则；单次神操作是运气，在与策略频率相称的足够样本下期望仍为正才叫优势。
2. **少数关键事件定一年结果，不是频繁操作**——绝大多数交易是噪音，年度盈亏由少数关键事件决定（**因策略而异**：方向性是几次大波动，卖方/价差是尾部亏损的管控）。核心是控换手、别在噪音里博小波段，不是追高频。
3. **能控的只有风险敞口，控不了方向**——锁死风险敞口是第一位。**用什么手段锁（止损/对冲/减仓/转价差/换合约）取决于你的持仓结构和策略，没有普适优先级**——别把任一种手段（如"买 put 对冲"只适用长仓/多头期权）当万能。过注（远超 Kelly 最优）长期破产概率趋近 1，方向对也救不了。
4. **交易一致性：同条件、同规则；改规则，有依据、有记录**——同一策略、可比条件和同一规则版本下，忠实执行进出场、仓位与风险标准，不随单笔盈亏或临场情绪换标准。新证据或环境变化可以修订，但须留痕并保留原始计划；一致的是决策过程，不是每次动作和结果。具体检查、版本与例外要求见 `_shared/trading-consistency.md`。
5. **仓位是观点的表达，也是心态的开关**——仓位大小匹配你的 **edge（由胜率与赔率共同决定，即 Kelly 逻辑）**，不是单看胜率高就重仓（高胜率低赔率的策略最优仓位可能很小）；仓位越大越输不起，越该为"睡得着"让渡些收益（心态保费）；全仓 = 有效杠杆过大、动作变形。
6. **能不能死拿是标的属性，不是态度**——宽基死拿是策略，个股蓝筹也有幸存者偏差；高波动/杠杆/加密类死拿常是心态自杀。类别决定止盈哲学，禁止跨类别迁移心态模板。
7. **预案把决策拆成两阶段：先判触发条件，再决定动作**——预案数量和反应速度之间有一道内化阈值（区分标准：能不能不看笔记说出触发条件；能，招数是资产；不能，招数是临场检索负担）。"不出招"要成立必须绑定具体的未触发条件（IV 分位没到 / 止损线没触及 / 催化剂没落地），缺了条件就是不可证伪的自我安慰。条件未满足可以不动；条件已满足却未按预案执行，要核查规则有效性、数据与执行约束，并按公理 4 记录偏差或修订，不能直接用结果判错。
8. **交易的唯一对象是不确定性：对它定价，不预测它**——胜率赔率的帕累托前沿要补三个边界条件：① 完整变量集含仓位与波动率环境（仓位定收益方差和破产概率，期权定价本身是波动率的函数）；② 前沿会随波动率环境移动，先判环境是否有利，别把边界外扩的免费改善归功于进出场调整；③ 期望值最大 ≠ 最优决策——期望值相同方差可以天差地别，实盘有资金和心理两重约束，目标函数是风险调整后收益（Kelly 对数效用），不是纯期望值。策略的成熟 = 三个递进的放弃：放弃预测换对条件的忠实执行，放弃期望值最大化换净值可持续，放弃出招冲动换只在边界上出手的纪律。

> 这几条一立，很多「该不该买、卖、割、加」的问题在被问出来之前就已经错了：假设自己能预测方向、在纠结沉没成本、用单次结果反推决策质量。（本句是设计说明，供 Skill 作者理解引导逻辑；不对用户复述，也不预设用户的问题错误。）

## 与交易能力模型的关系

`_shared/trading-ability.md` 的六个维度是这八条公理在行为层的可观察落点：公理回答「交易应当怎样」，能力模型回答「你现在做到了哪一步」。`elab-coach` 的诊断、处方、情景题与复测都挂回下表的公理。

对照的唯一定义在 `_shared/trading-ability.md` 六维表；本表按公理反向列出。

|---|---|
| 1 统计优势 | D6 复盘与统计；D3 进场（规则可重复） |
| 2 少数关键事件定结果 | D3 进场（计划外与噪音交易）；D5 执行一致性 |
| 3 能控的只有风险敞口 | D2 风险与仓位；D1 机制理解（算不清就锁不住） |
| 4 交易一致性 | D5 执行一致性 |
| 5 仓位是观点的表达，也是心态的开关 | D2 风险与仓位；心理角度 |
