# elab-model · 期望收益、Kelly 与期权结构计算

用本地脚本计算期望收益（EV）、盈亏平衡胜率、Kelly 资本比例，已支持期权结构的收益上限、亏损与盈亏平衡点等指标，以及组合的保证金压力、历史类比与组合重演。

- **什么时候用**：已有明确假设或合约参数，希望核对风险收益的数学关系。
- **提供什么**：有来源的胜率与盈亏假设，或行权价、权利金等所选模型需要的参数；做组合压力时提供持仓、维持保证金比例和日线 CSV。
- **得到什么**：可核验的脚本计算结果、单位说明、假设与模型警告。
- **边界**：不自行编胜率，不提供实时信号或精确期权定价；Kelly 是假设下的数学比例，不是实际仓位指令。组合压力是线性保证金近似加历史路径统计，不抓行情、不出挂单。回测执行引擎不随本套件分发。

示例：“按我给出的胜率和平均盈亏，计算 EV 与盈亏平衡胜率。”“按这份持仓和券商追保线，半导体再跌多少会碰到我的保底线？”
