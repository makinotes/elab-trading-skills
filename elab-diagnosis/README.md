# elab-diagnosis · 交易决策梳理与打法检查

把“该不该买、卖、加仓”等问题拆回判断依据、风险预算、规则、数据缺口与情绪驱动，也可检查整套投资打法。

- **什么时候用**：面对具体交易决定拿不准，或想梳理自己的决策方法。
- **提供什么**：当前困惑、原先判断、已有规则和风险信息；不知道的项目可明确说明。
- **得到什么**：需要厘清的关键问题、可核对的决策条件，以及方法层面的检查与引导。
- **边界**：帮助你想清楚，不直接替你给出当下买卖方向，也不是交易执行工具。

示例：“我想加仓，但不知道这是原计划还是情绪，帮我梳理一下。”

单纯查资料用 [elab-research](../elab-research/README.md)；复盘已有成交用 [elab-trade](../elab-trade/README.md)。
