# elab-benchmark · 投资方法对标与可复制性分析

用五重过滤审视交易者或策略的证据、逻辑与执行条件，识别样本和展示偏差，提取值得进一步验证的方法。

- **什么时候用**：想判断该向谁学习，或某套打法的哪些部分能借鉴。
- **提供什么**：对标对象、策略描述、可核验记录，以及你关注的具体方法。
- **得到什么**：证据充分程度、可复制条件、不可直接照搬的部分和待验证要点。
- **边界**：对标方法，不跟单；单凭晒单不能认证真实长期业绩，样本不足时不能给确定性结论。

示例：“这个交易者的方法有哪些可验证证据，哪些条件我无法复制？”

需要先归档富途或老虎博主公开内容时，用 [elab-futu-research](../elab-futu-research/README.md)。
