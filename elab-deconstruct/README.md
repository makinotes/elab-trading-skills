# elab-deconstruct · 期权与投资概念拆解

解释 IV、Delta 中性、对冲等概念的定义和操作含义，辨别易混术语、俚语与缺少公认定义的说法。

- **什么时候用**：一个词听过但说不清，或想知道某种操作对应什么专业概念。
- **提供什么**：术语、出现的语境，或你实际描述的操作。
- **得到什么**：概念解释、易混对照、适用与失效条件；标准概念可整理为概念卡。
- **边界**：解释方法不等于建议你当下执行某笔交易；含糊或自造词不会被包装成已成立的标准概念。

示例：“Delta 中性是指单个期权，还是整个组合？分别怎么理解？”

需要具体参数计算时可接 [elab-model](../elab-model/README.md)。
