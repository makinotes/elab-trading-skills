# elab-options · 期权工作台

管你自己的期权单子：开仓前按你自己的规则逐条核对一张单子，持仓时把移仓、被行权、保证金算清楚。

- **什么时候用**：开一张 BPS 或 sell put 之前想对一下自己的规则；快到期了想算移仓划不划算；担心被行权要准备多少钱；看不懂券商为什么扣这么多保证金。
- **提供什么**：每条腿的行权价、权利金、到期天数（有就带 Delta、IV），现价和张数；你自己的规则（第一次用时可以从你的口述或 playbook 整理出来，经你确认后存成规则文件）。
- **得到什么**：一张「对照你的规则」表（符合 / 没过 / 缺数据），到期最多赚、最多亏、盈亏平衡价，有 IV 时再加一张持有期盈亏表；移仓的净收付和新的最多亏；被行权要的现金和实际成本；保证金的算法。
- **边界**：规则是你的，工具只核对不替你改；不选标的、不选合约、不说该不该开；保证金是 Reg-T 口径估算，以券商显示为准；不同到期日的组合暂不支持。

示例：「帮我检查这张 BPS：卖 95 买 90 的 put，45 天，收 1.2，两张，对一下我的规则。」「这张快到期了，往后移一个月、行权价不变，算一下。」

概念不懂用 [elab-deconstruct](../elab-deconstruct/README.md)；IV 环境用 [elab-research](../elab-research/README.md)；复盘成交用 [elab-trade](../elab-trade/README.md)。
