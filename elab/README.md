# elab · 投研问题分流与数据连接引导

根据你想完成的任务，选择 EdgeLab Trading Skills 中相应的 Skill；需要券商数据时，先引导连接检查与数据源选择。

- **什么时候用**：不确定该用哪个 Skill，或想使用富途、长桥、IBKR 的数据。
- **提供什么**：你的问题、研究对象或希望完成的任务；如有指定数据源，一并说明。
- **得到什么**：对应的 Skill 入口与必要的连接引导，随后由目标 Skill 执行任务。
- **边界**：主入口负责分流，不替代各子 Skill 做分析；选择数据源不等于授权安装软件或执行交易。

示例：“帮我研究一个板块，该从哪里开始？”
