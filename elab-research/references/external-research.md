# 外部研究 Agent

仅当用户指定外部 Agent，或需要对一个独立子问题加深研究时读取。它是可选执行方式，不是新的顶层 Skill，也不替代券商数据连接。普通研究继续使用当前宿主可用工具。

## 可接什么

- 已在当前宿主提供的工具/API/MCP、可运行的本地CLI或Python接口：核验真实接口和可用权限，再按任务调用。
- 只有聊天网页或分享链接：不假设有API、不声称已调度。可以分析用户提供的导出报告，明确这是外部材料。
- GPT Researcher（`https://github.com/assafelovic/gpt-researcher`，Python接口及其链接的MCP服务）、Open Deep Research（`https://github.com/langchain-ai/open_deep_research`）、TradingAgents（`https://github.com/TauricResearch/TradingAgents`）、AI Hedge Fund（`https://github.com/virattt/ai-hedge-fund`）是可评估的候选，不代表已安装、已连接或已通过 EdgeLab 验证。读取所选项目当前官方说明、版本和许可证；不复制动态命令到本文件。
- 研究流程价值与交易收益声明分开验证。TradingAgents 等可用于研究方法比较，不把其输出当行情源、已验证策略或执行订单的授权。

## 有边界的委派

用户选定的研究方法、数据源限制、截止时点和只读边界随任务传递。把明确的子问题交出去；禁止“再找其他 Agent 继续研究”式递归派发，默认每个外部引擎只接一次有界任务，重试和追加深度依现有预算。

传入：问题、方法、时间范围、允许的数据源、必要的已脱敏材料、返回形式，以及时间/调用预算。没有明确预算时先说明预计额外调用与服务成本；不假定宿主订阅包含外部API费用。软件安装、新服务配置、账户授权与额外付费按当前授权处理，不在研究中临时自动安装。

默认只传公开材料和研究问题。用户提供的私有方法、持仓、订单、个人记录不能因“外部分析”自动上传；需要用户对目标服务和材料范围有明确授权。只授予必需的读取能力，不暴露交易写工具或凭证。

接收：结论与假设、原始引用及日期、所用数据、缺口和实际执行状态。已返回的模型文字仍是外部意见，不是 `[工具行情输出]`。引用打不开或找不到原文的关键主张标未核实；失败/超时就是失败/超时，不能用另一份回答冒充该引擎结果。

## 综合与评估

- 回到原始来源检查关键数字和引文；去掉重复转引，列出真实事实/假设分歧。多个 Agent 共识不自动升级置信度；独立上下文也不保证独立证据或无相关偏差。
- 比较时固定问题、数据截止时间、方法、可用工具和预算，记录是否确实增加有效证据、减少错误或发现反证，以及时间与成本。报告变长或角色变多不是增益。
- 不把内部评测题、标准答案或评分材料提供给被测引擎。验证结果与原始材料按内部仓规则保存；没有真实调用，只能说文档/接口审查完成。
- 同宿主多 Agent 辩论按主 Skill §三+ 执行；用户没选外部引擎，不为了“深度”自动换服务。
