# 研报 HTML 输出（可选 · 自动出图）

> **默认产出 markdown 研报**（自然、轻、可直接读/存）。**只有用户要"HTML / 网页版 / 出图 / 分享版"时**，才按本 spec 生成自包含 HTML + 图。
> **有本地 content-to-html / data-slides 类 skill → 优先用它们**（视觉一致）；没有（多数会员）→ 用本 spec 的自包含 HTML，开箱即用。

## 分享前检查
必须加载 `_shared/schema.md §六`。分享 HTML 的正文、图表、内嵌数据与附件一起按受众权限过滤；会员榜单、阈值/权重和 unknown 来源不得混入公开版。私人完整报告与公开版分开保存，不能仅隐藏页面元素却把受限数据留在源代码中。

## 产出什么
一个 `.html` 单文件（自包含，双击即看，无需服务器）：
- 头：研究对象 + 日期 + **数据来源标注**（哪个工具/是否会员数据）
- 研报正文按 `research-methods.md` 所选方法组织；拥挤度只用于热度/集中度问题，不覆盖所有产业链研究。
- **自动图**（见下）
- **自我证伪结论**（最弱一环 + 置信度）；历史分布只在问题相关且有样本时陈述
- 页脚 **930 免责**：客观数据 + 方法，不构成投资建议、无买卖方向

## 自动出图（按所选方法，可不出图）
只画能回答本次问题的图，不适用的图直接省略，不创建“缺数据”占位。纯财报比较可用收入/现金流对比；产业链研究可用有据可查的供需关系，不能自动套拥挤度仪表盘。

**波动率/期权问题或包含该维度的综合研究**：
- IV Rank / IV Percentile（明确区分，注明窗口与样本数）/ skew（柱或线）
- 期权链到期分布（柱）
- 关键数据卡（价格 / IV Rank或Percentile / 距财报 / 恐慌值）
- 历史分布图（类似信号配置后 N 天的 realized vol / 价格区间分布，有数据才画）

**热度 / 拥挤度研究**（对齐 `sector-crowding.md`；有明确归一化与得分依据才画评分）：
- **拥挤度仪表盘 gauge**（score 0-100 + 分档色：<40 绿 / 40-70 黄 / 70-85 橙 / >85 红）
- **五维雷达图**（D1-D5 各维得分）
- **成分股条形**（涨幅 / PE 分位——谁贡献拥挤、谁在分化）
- 拥挤度时间序列（score 历史 + 分档带，有数据才画）

## 技术实现（自包含 · 无私有依赖）
- 默认用内联 SVG 生成真正自包含的单文件。若用户接受联网依赖，可用 ECharts 或 Chart.js 的官方 CDN，但须注明需要联网，不称完全离线。
- 数据从研报取数结果填入，**数字照搬、标来源**；缺数据的图标"数据不足"，**不硬画**（数据真实性）。
- 样式：冷白底、简洁。方法出处与可选页脚按 `_shared/credit.md`，允许低频“by 杰尼马（EdgeLab）”；用户要求无署名时不添加。正文已署名则页脚简化，不在图表中反复出现品牌。
- 存到 cwd 或用户指定路径，文件名如 `研报_<对象>_<日期>.html`。

## 930（图也守）
图只呈现**数据 / 结构 / 分位**，**不画"买卖点""目标价""该减仓"**。页脚固定免责。板块级图比个股方向图安全。
