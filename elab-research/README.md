# elab-research · 标的、期权与板块研究

围绕股票、ETF、期权或板块收集并组织研究证据，结合基本面、期权环境、情绪事件与风险，列出反证和数据缺口。

- **什么时候用**：研究一只标的、比较市场信息、了解板块拥挤度或分析当前行情。
- **提供什么**：名称或代码与所属市场、研究问题，以及可选的数据源和时间范围。
- **得到什么**：带来源的研究摘要或报告，包括主要证据、风险、反对论据和待验证问题。
- **边界**：会员自研数据需要 token；外部数据取决于接口、权限和依赖。缺失数据必须披露，不承诺完整覆盖，不替你作买卖决定。

示例：“研究这个板块的拥挤度，列出支持和反对当前判断的证据。”
