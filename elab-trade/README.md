# elab-trade · 交易记录、账户数据读取与复盘

围绕你自己的交易，记录开仓前判断、更新持仓阶段想法、回填结果，读取并诊断持仓或交割单，再将经验整理为可复用的交易规则（playbook）。

- **什么时候用**：立案、更新判断、复盘自己的历史交易，或查看持仓、订单与成交。
- **提供什么**：本人判断和交易信息，或已授权的券商只读连接、导出文件。
- **得到什么**：本地决策记录、保留来源的历史快照、交易诊断及待验证的规则总结。
- **边界**：券商接入只读；订单不等于成交。不下单、改单或撤单，不把个人账户数据写进公开产品仓。

示例：“复盘这份导出的成交记录，把结果和当时的决策依据分开。”

研究外部标的用 [elab-research](../elab-research/README.md)；只保存一段对话进度用 [elab-save](../elab-save/README.md)。
